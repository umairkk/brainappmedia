# BrainApp Media Website

Multi-page marketing agency site for **BrainApp Media** (digital marketing, web development, and creative design).

## Project location

The Next.js application lives in [`brainapp-media/`](./brainapp-media/).

## Development

```bash
cd brainapp-media
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
cd brainapp-media
npm run build
npm start
```

## Stack

- Next.js App Router (static generation for all routes)
- Tailwind CSS v4
- Framer Motion (with reduced-motion and mobile-friendly animation defaults)
