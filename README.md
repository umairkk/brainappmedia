# brainappmedia

Premium digital marketing agency website (Next.js).

## Local development & preview

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). In Cloud Agent, the dev server binds to `0.0.0.0:3000` so **Preview** can connect.

Production preview after a build:

```bash
npm run build
npm run start
```
